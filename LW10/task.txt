Тема 10. Типизированные (бинарные) файлы

Задача 1. Дан бинарный файл последовательности double. Считать все значения в память,
найти максимум (первое вхождение) и вставить после него заданное число x. Если файл
пуст – записать единственное x. Сохранить изменения обратно в тот же файл. Затем
вывести содержимое файла построчно с фиксированной точностью (например, 3 знака
после запятой). Ошибки открытия/чтения/записи сообщать кратко и без аварийного
завершения.

Задача 2. Дан бинарный файл записей {std::string brand; double price;}, где brand – строка
без пробелов. Считать все записи, отсортировать по price по возрастанию (стабильность
необязательна) и переписать во второй бинарный файл. Вывести содержимое исходного и
нового файлов в читаемом виде: «brand price» построчно, с фиксированной точностью.
Проверить корректность открытия файлов и формата. Для строк использовать схему
«длина+байты».
