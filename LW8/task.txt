Тема 8. Строки
Задача 1. Считать строку целиком с помощью std::getline. Считается, что слова разделены ровно одним пробелом, без ведущих/замыкающих пробелов. Вывести количество слов, то есть число фрагментов между пробелами. Пустая строка даёт 0. Регулярные выражения и сторонние библиотеки запрещены. Разрешается прямой проход по символам. Примеры: «hello world» → 2; «a b c» → 3; «» → 0.
Задача 2. Считать произвольную строку (включая пробелы). Удалить повторяющиеся символы без учёта регистра, сохранив первые вхождения; регистр для сравнения игнорировать, но исходный регистр первого появления сохранять. Пробелы и знаки препинания сохранять, однако повторов не допускать. Вывести результат одной строкой. Примеры: «Программа» → «Прогам»; «A-a-B-b» → «A-B-». Рекомендуется массив булевых флагов размером 256 или ассоциативный контейнер для учёта встреченных символов.
